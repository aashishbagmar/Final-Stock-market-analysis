## Goal
Update the Backtracking module so `run_backtest.py` can accept multiple comma-separated tickers and backtest them in one run, while fixing the broken imports/exports that currently crash the CLI.

## Constraints
- No new dependencies.
- Preserve existing single-ticker CLI behavior (`python run_backtest.py AAPL 7`).
- Reuse existing backtest logic in `Backtracking/backtest.py`.
- Keep CSV output format backward-compatible.
- Sequential execution only (respects existing yfinance rate limiter).

## Chunks

### Chunk 1 — Fix broken package exports
- **Scope:** `/mnt/e/Stock prediction CLG PROject/Backtracking/__init__.py`
- **Depends On:** None
- **Accept When:**
  - `from Backtracking import backtest_model, run_comprehensive_backtest, fetch_historical_data` succeeds without `ImportError`.

- **Open Questions:** None

## Decision Log
- **CLI ticker format:** comma-separated, chosen by user.
- **Implementation approach:** Option B — add reusable multi-stock runner in `backtest.py` and fix broken exports, recommended and approved.
- **Compatibility:** Single-ticker invocation must keep working.

## Risks
- **yfinance rate limiting** when running many tickers sequentially. *Likelihood: Medium.* *Mitigation:* Reuse existing `RateLimiter`; sequential calls already respect it.
- **Long runtime** due to LSTM training per ticker. *Likelihood: Medium.* *Mitigation:* Keep `lightweight=True` and existing epoch defaults inside `run_backtest`.
- **Old function names referenced elsewhere.** *Likelihood: Low.* *Mitigation:* Search repo for any usages and update or alias accordingly.
